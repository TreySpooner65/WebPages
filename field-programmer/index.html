A simpler workflow

Connect. Organize. Write.

Field Programmer keeps the process understandable while protecting the radio image you started with.

Connect your radio

Choose a supported radio and connect by Bluetooth or a compatible USB programming cable.

Read and edit

Load the radio, organize channels, and change the settings you need.

Review and program

Confirm the changes, then write the updated configuration back to the radio.

Built with field use in mind

Your radio plan stays yours.

Core programming data is stored locally on your device. Field Programmer does not require an account for normal radio programming, and you control when diagnostic information is shared.

Field Programmer is preparing for release on Google Play. Radio features and connection methods vary by model and Android device.
